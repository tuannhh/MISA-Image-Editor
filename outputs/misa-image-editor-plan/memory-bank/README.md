# Memory bank
Ngày cập nhật: 17/09/2026.

Memory bank là các file nằm cùng dự án, được cập nhật theo công việc thực. Không giả định trợ lý tự nhớ qua mọi cuộc trò chuyện nếu chưa đọc lại file.

## Cách tiếp tục
Đọc README gốc → activeContext.md → decisions.md → progress.md → handoff/CURRENT.md. Khi sửa phạm vi, sửa PLAN/ROADMAP trước rồi ghi quyết định. Cuối mỗi phiên ghi việc thực làm, bằng chứng kiểm thử, chỗ dở dang và hành động tiếp theo.
Không đánh dấu Done từ kế hoạch. Không lưu mật khẩu hoặc ảnh người dùng vào memory bank.

## English summary

The memory bank is project-local documentation that preserves decisions and working context between sessions. Read the root README, `activeContext.md`, `decisions.md`, `progress.md`, and `handoff/CURRENT.md` before continuing. Update PLAN/ROADMAP before changing scope, then record the decision; at the end of each session record completed work, test evidence, unfinished work, and the next action. Do not mark work done from a plan alone, and never store passwords or user photos here.

# P0 tone curve update

The Editor now has a four-region parametric Tone Curve with Shadows, Darks, Lights, and Highlights controls from -100 to 100. The values are stored in recipe-v1 under `tone_curve`, participate in preview and batch export, and can be selected in Copy Settings for batch paste.

This is a compact parametric curve for the P0 Windows slice. An interactive RGB point-curve editor and HSL Color Mixer remain later milestones.
